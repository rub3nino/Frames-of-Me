# RePhoto

RePhoto trova le foto di un evento a partire da un selfie. Il confronto volti passa da `FaceEngine`: in locale `FACE_ENGINE=fake`, in produzione Amazon Rekognition in `eu-central-1`. Il selfie si cancella dopo la ricerca.
